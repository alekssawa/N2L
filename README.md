A modern web application built with React and Vite, designed to provide an engaging user experience for the N2L platform. This client-side application includes features such as interactive sections, dynamic content management, and seamless navigation.

---

## ✨ Features
- 🎨 Tailwind CSS for responsive design and styling  
- 🔍 Algorithm section showcasing complex computations  
- 📧 Contact form integrated with backend services  
- 🌟 Community section to foster engagement  
- 💰 Shop area featuring gift items 

---

## 🛠️ Tech Stack

**Frontend:**
- React + Vite
- TypeScript
- Tailwind CSS for styling
- react-router-dom for routing

**Development Tools:**
- ESLint for code linting
- Prettier for code formatting
- GitHub Pages for deployment

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alekssawa/N2L.git
   cd N2L/client
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   This will start the Vite development server and open the application in your default web browser.

4. **Build the project for production:**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```

## 📂 Project Overview

The project is structured as follows:

- **eslint.config.js**: Configuration file for ESLint.
- **package.json**: Contains all dependencies and scripts for the project.
- **public/**:
  - README.md: Placeholder documentation within the public folder.
- **src/**
  - **App.tsx**: Main application component.
  - **assets/**: Directory for static assets like icons and images.
    - **icons/**: Folder for icon images.
    - **img/**: Folder for other image files.
  - **components/**:
    - **footer/**: Footer component.
    - **header/**: Header component.
    - **main.tsx**: Entry point for the components.
  - **pages/**: Organized by functional areas of the application.
    - **Algorithm/**: Algorithm-specific pages and sections.
    - **Contacts/**: Contact-related pages and forms.
    - **General/**: General-purpose pages and sections.
    - **Shop/**: Shop pages and gift-related sections.
  - **styles/**:
    - vite-env.d.ts: TypeScript declarations for Vite environment variables.
  - **tsconfig.app.json**: TypeScript configuration for the application.
  - **tsconfig.json**: Main TypeScript configuration.
  - **tsconfig.node.json**: TypeScript configuration for Node.js.
  - **vite.config.ts**: Configuration file for Vite.
